# Radar Trades

Application Android qui scanne les contrats crypto USDT de Binance Futures et affiche le Top 3 des setups à surveiller
(tendance 1J/4H, zones 4H, RSI 1H), avec plan d'entrée, stop, objectifs et taille de position.

L'application lit uniquement les données de marché publiques de Binance. Elle ne demande aucune clé API et ne passe aucun ordre.

## Installer

Télécharge `radar-trades.apk` depuis la dernière version : https://github.com/aminebenkhadra-dotcom/radar-trades/releases/latest

Chaque modification poussée sur `main` recompile l'APK automatiquement (onglet Actions).
